### lgbm_ltr.py: LGB-NEW-1 per-date bucketing

Critical fix. Old code used global quantile → ranking signal lost.
New code:
```python
for gs in group_sizes:
    slice_y = y[offset:offset + gs_int]
    ranks = np.argsort(np.argsort(slice_y, kind="stable"), kind="stable")
    if gs_int >= n_buckets:
        buckets = (ranks * n_buckets) // gs_int
    else:
        buckets = ranks
    out[offset:offset + gs_int] = np.clip(buckets, 0, n_buckets - 1)
```

Edge cases checked:
- gs=0: skip (no rows in group)
- gs<n_buckets: ranks used directly (no bucketing)
- All-equal labels in group: argsort gives [0..n-1] (stable) → ranks distinct
  - Same behavior as old global path; not new artifact
