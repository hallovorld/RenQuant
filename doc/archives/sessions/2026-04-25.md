### NGBoost retrain anomaly (TBD)

`NGBoostHead.train: dropped 104360/120577 rows with NaN/inf in features/label/weight`
That is **86.5% of the panel dropped**. Root cause: `np.isfinite(X).all(axis=1)`
drops a row if ANY of the 41 features is NaN. Patchy factors:
- `insider_net_buy_90d_z` — 44/99 tickers (55% NaN coverage)
- hourly aggregates (`morning_drift_z` etc.) — 83/99
- minute aggregates (`m_*_z`) — 83/99
- β-warmup early rows
NGBoost (unlike XGBoost) has no native NaN handling, so the row-drop is the
mechanism. Fix in flight: median-fill features (with optional impute toggle)
instead of dropping.
