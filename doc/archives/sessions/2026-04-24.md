## Section A — feature shipping (first half of session)

### A1. Per-model TTL gate (`training.model_ttl_days`)

`scripts/train_104.py` plus per-ticker TTL gate inside `_run_ticker_chain`:
when the artifact's `trained_date` is within TTL days, skip retraining for
that ticker. Currently set to 1 (idempotency only); raise to 7-14 to actually
reduce per-ticker retrain cost.

Tests: `tests/test_model_ttl.py` (10 tests).

### A6. Panel-exit V2 OR mode

`risk.panel_exit.trigger_mode = "and"|"or"`. AND mode (V1) fired 0 times in

Both modes still default off; A/B inconclusive on current panel.

Tests: `tests/test_panel_exit_v2.py` (9 tests).

### A7. sim/runner robustness tooling

* `run_backtest(snapshot=True)` is now the **default**. Every sim freezes
  artifacts/models/config to a tmp workspace for the run; concurrent
  retrains can't corrupt mid-flight.
* `sim/analysis.strip_top_n_trades(result, n=3)` — notebook robustness
  check that recomputes APY excluding the top-N realized trades. Answers
  "am I riding 3 lottery winners?".

Tests: `tests/test_run_backtest_snapshot.py` (2), `tests/test_sim_analysis.py` (8).

### A8. Test infrastructure

* `pytest.ini` enables `pytest-xdist` (`-n auto`), `OMP/MKL=1`,
  `RENQUANT_NO_NOTIFY=1` globally. Suite runs 14 sec instead of hanging
  25 min.
* `kernel.net_safety` switched from non-daemon ThreadPoolExecutor (which
  kept pytest-xdist workers alive on stuck network calls) to per-call
  daemon thread.
* All timeout tests' sleeps shortened from 5-60 sec to ~1 sec each.

### Pattern observations (silent-bug enablers)

* **A1**: each new feature class needs adds in 5 places (compute fn,
  TickerPanelFactorJob, FactorZScoreTask raw_cols, FactorZScoreTask output
  loop, prepare_inference_panel_frames LoadXBarsTask). Brittle — refactor
  to a feature registry next session.
* **A2**: try/except around per-ticker tasks silently drops failed
  tickers without an aggregate counter or alert.
* **A3**: NaN at inference vs train distribution mismatch — tree models
  handle NaN but training-sparse vs inference-dense changes the routed
  branch.
* **A4**: Panel + NGBoost feature_cols invariant not asserted at load time.

Defensive regression tests added so each pattern has at least one example
caught at CI: `tests/test_session_silent_bugs.py`,
`tests/test_session_regressions.py`, `tests/test_inference_no_autofetch.py`.
