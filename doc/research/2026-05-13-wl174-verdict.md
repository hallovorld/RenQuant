## Interpretation

**Hypothesis (Grinold-Kahn fundamental law)**: IR_new/IR_old =
√(N_new/N_old). For wl174: √(174/103) = 1.30 → +30% IR upper bound,
IF the model's IC is preserved. Result: IC NOT preserved (essentially
zero pooled Δ; high regime-conditional variance).

**Why didn't lazy-swap work?**:
1. **Calibrator miscalibration**: Existing calibrator was fit on wl103
   score distribution. Adding 71 names shifts the distribution
   (different sector mix: financials/energy/industrials added). Model
   scores may be systematically biased on new tickers.
2. **Aux artifact mismatch**: Correlation matrix regenerated for wl174,
   but GMM regime / embeddings / earnings still wl103-vintage. Some
   noise sources.
3. **Bottom-feeder effect**: Adding more names = wider cross-section.
   Bottom decile gets worse-quality picks on average. In LOW_CALM
   (sideways markets), these drag down portfolio.

## Decision

**NOT promoting wl174 to prod.** Tier 1 floor not breached, Tier 2 not
cleared. Production unchanged.

## Proper wl174 test (NOT done today)

Full retraining variant requires ~4-6h additional compute:
1. Retrain panel-LTR using wl174-only training data (not 292-ticker)
2. Retrain calibrator on wl174-only scores
3. Regenerate GMM regime on wl174 universe
4. Regenerate embeddings if used
5. 16-window sim

This is the "Wave 1A retrain" path documented in
doc/research/watchlist-100.md. The wl183 prior failure (2026-05-05)
was on a different greedy admission, so it doesn't definitively
predict the wl174 retraining outcome.

**Recommend**: defer wl174 retraining variant to next session. If
pursued, run as a separate pre-registered experiment.
