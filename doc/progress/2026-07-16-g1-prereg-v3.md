# G1: Equal-weight prereg v3 — address all 4 codex scientific blockers

Date: 2026-07-16

## Problem

Umbrella PR #465 (v2) received CHANGES_REQUESTED with 4 scientific
blockers from codex review (2026-07-14). Additionally, the branch
violated the single-identity policy (mixed hallovorld + haorensjtu-dev
commits).

## Changes (v3 vs v2)

### 1. Self-financing rule (blocker 1)

Replaced the common dollar exposure `E_t` with a self-financing design
using a common exogenous risk scalar `g_t`:

- `g_t = risk_engine(snapshot_t) / reference_NAV_t` — computed once from
  the frozen reference snapshot, recorded in the shared snapshot
- Each arm targets `g_t * own_NAV` — self-financing, no capital transfers
- Arm-specific feasibility rules when budget exceeds available capital
- Report BOTH gross ratio `g_t` AND per-arm dollar exposure (gate G6)
- Explicitly: costs and tax are arm-specific (same accounting model,
  different realized amounts because trades differ)

### 2. Power simulation (blocker 2)

Added section 4.6 (pre-activation simulation) requiring:

- Synthetic DGP with calibrated autocorrelation from holding-period
  overlap and realistic turnover
- 5,000 Monte Carlo trials under null (type-I <= 0.10) and MDE
  alternative (power >= 0.80)
- Horizon adjustment: increase T in 20-session increments if power < 0.80
  at 240 sessions; hard ceiling 480 sessions
- All simulation outputs frozen in the activation commit

Replaced naive percentile bootstrap on 12 block summaries with
moving-block bootstrap (MBB) on daily paired returns:
- Block length `b = ceil(1.75 * max_holding_days)`, capped at 40
- 10,000 MBB resamples, 10th percentile = lower bound
- 12-block summaries retained as DESCRIPTIVE diagnostics only

### 3. Regime descriptive-only (blocker 3)

New section 4.2 explicitly makes ALL regime results descriptive:
- Regime breakdowns are hypothesis-generating, not confirmatory
- No regime-specific deployment claim from any number of blocks
- Future regime claims require separate pre-registration with
  multiplicity control and independent power
- Go/no-go based SOLELY on pooled primary test

### 4. Frozen executable schemas (blocker 4)

Added section 6.5 with concrete frozen schemas:
- `shadow_telemetry.parquet`: 16 typed columns including per-arm cost,
  tax, exposure, feasibility flags
- `prereg_verdict.json`: full gate results, per-arm summary, regime
  descriptive breakdown

Section 7 explicitly gates activation:
- Document is RFC until activation commit fills ALL TBD fields
- No observation before activation commit pushed to main
- Added `g_t_formula_digest`, `feasibility_rule_digest`,
  `verdict_generator_commit`, schema digests, and full simulation
  outputs to the activation fields

### 5. Single-identity rebuild

New branch `design/g1-ew-prereg-v3` from current main, single
hallovorld-only commit, no Co-Authored-By trailers. New PR supersedes
